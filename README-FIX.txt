MY MONEY V2.2.1 FIXED
แก้ Code.gs ใหม่ทั้งไฟล์ ไม่ต้องแก้ทีละบรรทัด

1. Apps Script > Code.gs
2. เลือกโค้ดเดิมทั้งหมด แล้วลบ
3. คัดลอก Code.gs ใน ZIP นี้ไปวางทั้งหมด
4. Save
5. Deploy > Manage deployments > Edit > New version > Deploy
6. เปิด /exec เดิม ต้องเห็น apiVersion 2.2.1
