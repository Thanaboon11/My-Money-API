My Money — Safe Sync Recovery (9 ต.ค. 2569)

สำคัญ: ก่อนแก้ไข ให้ทำสำเนา Google Sheets และกดปุ่ม "สำรองข้อมูลในเครื่อง" ในแอปเดิมถ้าทำได้ ห้ามล้างข้อมูล Chrome/ถอนแอป

1) สำรองชีต: ไฟล์ > ทำสำเนา
2) ใน Apps Script ให้แทนที่เนื้อหา Code.gs เดิมด้วย Code.gs ใน ZIP (อย่าสร้าง Code.gs ซ้ำ) แล้ว Deploy > Manage deployments > Edit > New version > Deploy
3) GitHub: อัปโหลด index.html, app.js, sw.js, style.css, manifest.json และไอคอนตามต้องการจาก ZIP ไปแทนไฟล์เดิม
4) เปิดแอปเดิมในมือถือโดยไม่ล้างข้อมูล แอปจะลองส่งคิวเก่า และดึงบัญชี/หมวดหมู่จากชีตแม้มีคิวค้าง
5) กด "สำรองข้อมูลในเครื่อง" เก็บไฟล์ JSON ไว้ก่อนทำรายการใด ๆ

การซ่อมนี้ไม่แก้แถวข้อมูลใน Google Sheets ที่ถูกสลับอยู่แล้ว ต้องตรวจหัวคอลัมน์และรายการที่ผิดก่อนซ่อมข้อมูลย้อนหลัง
ถ้าคิวค้างไม่หาย ให้ส่งข้อความผิดพลาดจาก Apps Script Executions และไฟล์สำรอง JSON (ปิดข้อมูลส่วนตัวก่อน) เพื่อตรวจอย่างปลอดภัย
อย่ารัน ThaiView.gs หรือ BalanceTable.gs ซ้ำระหว่างตรวจความถูกต้องของชีต
