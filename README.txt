MY MONEY — FINAL

ชุดนี้รวมการแก้ทั้งหมด และมี README.txt เพียงไฟล์เดียว

แก้แล้ว
- รายรับ/รายจ่าย: เลือก “บัญชี” เพียงช่องเดียว
- เฉพาะโอนเงิน: จึงมีบัญชีต้นทาง + บัญชีปลายทาง
- บันทึก/แก้ไข/ลบ: เปลี่ยนหน้าแอปทันที ไม่ต้องรอ Google Sheets
- ระบบคิวซิงก์: กดบันทึกหลายรายการต่อกันได้ รายการจะเข้าคิว ไม่ถูกการซิงก์เก่าเขียนทับ
- ถ้าเน็ตหรือ Apps Script ช้า รายการที่รอซิงก์เก็บในเครื่องและลองใหม่อัตโนมัติ
- ID รายการสร้างจากแอป ทำให้เพิ่มแล้วแก้/ลบต่อได้แม้รายการก่อนยังรอซิงก์
- ป้องกันการเพิ่มซ้ำเมื่อเครือข่ายตอบกลับช้า
- เงินที่แม่ให้: รองรับ “แม่”, “แม่ให้”, “แม่ให้เงิน” และข้อความอื่นที่มีคำว่า “แม่”
- แก้คำผู้ให้ย้อนหลังแล้วสรุปเงินที่แม่ให้เปลี่ยนตาม
- การแก้ไข/ลบใน Google Sheet ยังอัปเดตกลับเข้าแอปเมื่อไม่มีงานค้าง
- หมวดหมู่เพิ่ม/แก้ไข/ลบ(ซ่อน)ได้

ติดตั้งครั้งเดียว
1) Apps Script: แทน Code.gs เดิมทั้งไฟล์ > Save > Deploy > Manage deployments > Edit > New version > Deploy
2) เปิด /exec เดิม ต้องเห็น apiVersion = FINAL-1.0
3) GitHub Pages: แทนไฟล์เดิม 7 ไฟล์: index.html, style.css, app.js, manifest.json, sw.js, icon-192.png, icon-512.png
4) Code.gs ไม่ต้องอัปโหลด GitHub

ไม่ต้องสร้าง Sheet ใหม่ ไม่ต้องสร้าง Repository ใหม่ และไม่ต้องเปลี่ยน API URL
