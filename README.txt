MY MONEY — SHEET SYNC FIX

แก้ปัญหา: ลบรายการใน Google Sheets แล้วแอปยังค้างรายการเก่า

รอบนี้ไม่ต้อง Deploy Apps Script
ไม่ต้องแก้ Code.gs

ทำเพียง GitHub 2 ไฟล์:
1. app.js
2. sw.js

หลัง GitHub Pages อัปเดตแล้ว เปิดเว็บ/แอปใหม่หนึ่งครั้ง
เมื่อไม่มีรายการที่รอซิงก์ Google Sheets จะเป็นข้อมูลหลัก:
- ลบใน Sheet -> แอปลบตาม
- แก้ใน Sheet -> แอปแก้ตาม
- แอปตรวจ Sheet ประมาณทุก 4 วินาที และทันทีเมื่อกลับเข้าแอป

Local cache จะคุ้มครองเฉพาะงานที่ยังรอส่งเท่านั้น และจะไม่เอารายการที่ Sheet ลบแล้วกลับมาแสดงอีก
