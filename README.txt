My Money — แก้แจ้งเตือนซิงก์ซ้ำ (ชุดปลอดภัย)

สำคัญ: ชุดนี้ไม่ได้แก้ข้อมูลใน Google Sheets และไม่ได้ลบคิวรายการค้าง

1. สำรองข้อมูลบนคอมและมือถือแยกกัน โดยกดปุ่ม สำรองข้อมูลในเครื่อง ในแต่ละเครื่อง
2. สำรอง Google Sheets: ไฟล์ > ทำสำเนา
3. บน GitHub อัปโหลด app.js และ index.html ไปแทนไฟล์เดิมเท่านั้น
4. เปิดเว็บใหม่บนทั้งสองเครื่อง รอให้ข้อมูลโหลด อย่าล้างข้อมูลเว็บไซต์
5. ถ้ายังขึ้น รอซิงก์ ให้เก็บไฟล์สำรองและส่งข้อความข้อผิดพลาด / ภาพหน้าจอมาเพื่อตรวจคิว

สิ่งที่เปลี่ยน: หยุดแสดง Toast ซ้ำทุกครั้งเมื่อข้อผิดพลาดเดิมยังค้าง, ลดการโหลดซ้ำจาก 4 เป็น 15 วินาที, แสดงจำนวนรายการรอซิงก์ตามจริง, รักษาคิวเดิม และเก็บสถานะในไฟล์สำรอง

ข้อจำกัด: ถ้าคิวมีคำสั่งที่เซิร์ฟเวอร์ปฏิเสธจริง รายการจะยังรอซิงก์จนกว่าจะซ่อมสาเหตุ การซ่อนแจ้งเตือนไม่ใช่การยืนยันว่าข้อมูลซิงก์แล้ว และไม่ควรลบคิวอัตโนมัติ
